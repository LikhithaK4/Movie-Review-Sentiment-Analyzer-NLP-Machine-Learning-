Movie Review Sentiment Analyzer

The Movie Review Sentiment Analyzer is a Natural Language Processing (NLP) and Machine Learning project that automatically classifies movie reviews as positive or negative. The application leverages text preprocessing, TF-IDF feature extraction, and a Logistic Regression model to analyze user-provided reviews and predict their sentiment with 89% accuracy.

A user-friendly web interface was developed using Streamlit, allowing users to enter movie reviews and receive instant sentiment predictions. This project demonstrates the complete machine learning workflow, from data preprocessing and model training to evaluation and deployment.

Features

* Sentiment classification of movie reviews (Positive/Negative)
* Text preprocessing using NLTK (tokenization, stopword removal, stemming/lemmatization)
* TF-IDF vectorization for feature extraction
* Logistic Regression classifier with 89% prediction accuracy
* Interactive web application built with Streamlit
* Clean, responsive, and easy-to-use interface

Tech Stack

* Programming Language: Python
* Machine Learning: scikit-learn
* Natural Language Processing: NLTK
* Data Processing: Pandas, NumPy
* Feature Extraction: TF-IDF Vectorizer
* Model: Logistic Regression
* Web Framework: Streamlit
* Version Control: Git

 Workflow

1. Load and preprocess the movie review dataset.
2. Clean and normalize text using NLP techniques.
3. Convert text into numerical features using TF-IDF.
4. Train a Logistic Regression model.
5. Evaluate the model using classification metrics.
6. Deploy the trained model with Streamlit for real-time sentiment prediction.

 Results

* Model Accuracy: 89%
* Fast and reliable sentiment prediction
* Demonstrates practical application of NLP and supervised machine learning for text classification
